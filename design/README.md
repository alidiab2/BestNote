# Design Board

Interactive mockups of BestNote, made **before** UI code. UI tasks implement what is agreed here.

Open locally:
```bash
cd design && python3 -m http.server 8765   # then http://localhost:8765
```
Screens: design system, library, editor (tap the active pen for its popover), page manager, Smart Board, phone & Fold. The toggles switch light/dark and RTL (Arabic).

`tokens.css` maps 1:1 to `:core:designsystem` (colors, type, shapes, motion). Change a token here first, then in code.

Status: **v1, awaiting approval.**
