## Issues

### Broken

**B1. Snackbars with an action never go away (fixed)**
Material 3 `showSnackbar(actionLabel = …)` defaults to `SnackbarDuration.Indefinite`. "Pen detected: fingers now
scroll and zoom · Settings" stayed over the bottom of the page for 20+ minutes and covered ink and the page counter. The
same happened to "Page added / Page deleted · Undo" in the page manager, "Page cleared · Undo", "Recording saved ·
List" and "N pages inserted · Undo".
Repro: new notebook, write one stroke with the pen, wait. Screenshots: `w1.jpg`, `paste.jpg`, `preord.jpg`.
Fix: these snackbars now use `SnackbarDuration.Long` (the page manager's non-undo messages stay `Short`).

**B2. Undo takes back several strokes (whole words) at once (fixed)**
androidx.ink hands over finished strokes in batches when the pen lifts and lands again quickly (normal fast
handwriting). `PagedDocumentView.onStrokesFinished` recorded the whole batch as one undo step: with 29 strokes on the
page, two taps on Undo removed 10 strokes; Redo put back 8 and then 2. Goodnotes undoes one stroke per tap.
Repro: replay `mixed.json`, tap Undo twice, compare stroke counts (`am broadcast -a app.bestnote.debug.STATE`).
Fix: each finished stroke is recorded as its own undo step.

**B3. A double tap on an in-app back arrow can leave a blank screen (fixed)**
`onBack = nav::popBackStack` for the editor, settings, templates and Smart Board. A second tap that lands before the
transition ends pops the library too, and the NavHost is left empty (blank window; the system Back then leaves the
app). Found by reading the code. A double tap on the emulator ended with the launcher in front while the app's
activity was still "resumed"; another agent shares the emulator, so this is not a clean repro.
Fix: these back callbacks only pop when there is a screen behind (`previousBackStackEntry != null`).

## Harness notes
- Replays are fitted to the canvas with a 112 dp inset, which on this emulator puts the first line of `mixed.json`
  above page 1 (in the desk), where it is dropped. Use `--ef top 160` for full-page corpora.
- Other agents bring their own builds to the front between lock holds: check `topResumedActivity` before tapping.
- Lasso tap / drag / resize stroke files can be generated in mm with the same 180x60 frame as `mixed.json`, so
  coordinates line up with the writing.
