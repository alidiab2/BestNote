# 01 – Pens and Drawing Tools

Tapping a selected tool a second time opens its settings. [V]

## Pen tool
Three pen types live under one Pen tool.

| Type | Behavior | Status |
|---|---|---|
| Fountain Pen | Pressure-sensitive ink for everyday notes and sketches | [V] |
| Ball Pen | Consistent line width, not pressure-sensitive | [V] |
| Brush Pen | Highly pressure-sensitive, for lettering and expressive strokes | [V] |

### Pen settings
- Tip Sharpness: stroke end from round to sharp, where supported [V]
- Pressure Sensitivity: how much line width responds to stylus pressure [V]
- Stroke Stabilization: smooths hand jitter [V]
- Tip Flatness: flat tip, on some Apple devices only [V]
- Thickness: preset sizes plus slider [U]
- Color: preset swatches, full color picker, saved custom colors [U]
- Draw in Straight Line [U]
- Dashed line [U]
- Favorite pens: saved pen + color + thickness presets in the toolbar [U]

## Pencil tool
Separate tool that produces a graphite effect. [V]
- Pressure sensitivity [V]
- Tilt shading: vertical tilt gives fine lines, horizontal tilt gives soft shading [V]
- Thickness and color [V]
- No confirmed tip-shape options (chisel/round) [U]

## Highlighter tool
Separate tool; underlying content (drawing or PDF text) shows through. [V]
- Draw in Straight Line: auto-straightens strokes [V]
- Stroke Stabilization [V]
- Thickness, color, opacity [U]
- Tip shape (round / flat) [U]
- Highlighter ink can move together with pen ink when a selection is moved with Lasso [V, user report]

## Eraser tool
- Pixel (partial) eraser: erases part of a stroke [V]
- Stroke / object eraser: erases the whole stroke [V]
- Switch mode by double-tapping the icon [V]
- Option to erase highlighter only, without touching ink [V]
- Scribble to erase: scribble over writing to delete it [V]
- Eraser size [U]
- Auto-deselect: return to previous tool after erasing [U]

## Shape tool
- Snaps hand-drawn circles, rectangles, triangles and similar shapes to clean versions [V]
- Fill shapes [U]

## Laser pointer
- Temporary pointer for presentations; settings details not found [V existence / U settings]

## Zoom Window
- Magnified writing area for fine handwriting [V]

## Not found (do not assume these exist)
