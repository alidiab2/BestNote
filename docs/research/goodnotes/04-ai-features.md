# 04 – Smart Features (on-device only)

Only features that can run locally with no account or cloud service.

| Feature | Description | Status |
|---|---|---|
| Handwriting search | Find typed text, handwriting and sketches | [V] |
| Handwriting Extraction | Handwriting to readable text | [V] |
| Spellcheck | Fixes handwriting typos in the user's own handwriting (English, Spanish, German, Dutch at launch) | [V] |
| Word Complete | Experimental autocomplete for handwriting (English) | [V] |
| Math Assist | Write `=` after an expression to get the solution; finds errors | [V] |
| Audio transcription | Record and transcribe audio | [V] |
