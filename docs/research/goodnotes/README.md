# Goodnotes Feature Reference (research)

Complete list of Goodnotes features (big and small), collected as a reference for BestNote. How each item maps to a BestNote milestone is in [`../../product/feature-matrix.md`](../../product/feature-matrix.md).

**Scope: everything local.** No accounts, sign-in, sync, cloud AI, sharing, collaboration or online services. See "Excluded" below.

## Confidence legend
- **[V]** Verified from an official or third-party source (see Sources).
- **[U]** Unverified: from general knowledge, confirm in the app before relying on it.

> Goodnotes official support pages (support.goodnotes.com) returned 403 when fetched, so tool-level details marked [U] still need checking in the app.

## Excluded (need an account, cloud or network)
- Sync across devices, iCloud, offline-mode toggles
- Accounts, plans, pricing, admin controls, Workspaces
- Sharing, real-time collaboration, Whiteboard collaboration, live cursor, Classroom
- Cloud AI: Ask Goodnotes, summaries, mind maps, project plans, AI image creation, AI text editing, AI Lasso, ChatGPT integration, Meeting Notes
- Online services: template/sticker marketplace, GIPHY search
- Privacy/compliance certifications (cloud-service related)
